# Repository contribution instructions

- For changes requested in this repository, the user has authorized committing and pushing completed, validated changes directly to `main`; do not open a pull request unless the user asks for one.
- Keep changes focused on the request and run the most relevant available verification before publishing.
- A push to `main` triggers the GitHub Pages deployment workflow. The published site keeps its existing URL: https://gabo28yt-droid.github.io/Tundra/
- After pushing, verify that the deployment workflow succeeds before reporting the site as updated.
